# README media

These are captures of the running local Trace app. The geometry comes from the included Northbank Studio IFC files; the building and its material rates are synthetic example data.

| File | Content |
| --- | --- |
| `trace-workspace.jpg` | Full model review workspace in the new white studio interface, captured 20 October 2026 |
| `trace-revisions.jpg` | Full revision workbench with neutral baseline and lime current geometry, captured 20 October 2026 |
| `trace-evidence.jpg` | Selected slab with an undeclared volume and excluded allowance, captured 20 October 2026 |
| `trace-walkthrough.gif` | Seven actual screens of the redesigned app, captured 20 October 2026 and assembled with reading pauses |
| `trace-backup.jpg` | Workspace restore preview with both models, assumptions, note counts and replacement controls, captured 20 October 2026 |

The GIF is a screen sequence, not a continuous video or a rendering-performance demonstration. Its frames show the model, floor separation, a missing-quantity finding, the door revision overlay, baseline geometry, current geometry, and source calculations. No interface elements or model geometry were added to the captures. The older forest-green interface captures have been replaced.

To reproduce the sequence, run the frontend, open the bundled example and follow the walkthrough in the main README. Use the default rates and clear any review selection before the first frame. The source fixtures are generated by `backend/generate_demo.py` and can be imported through the same service as other IFC files.
